# OSINT Gathering Methodologies

## Passive Collection
- Public records, search engines, social media/X, WHOIS/DNS lookups, web archives.

## Active Collection
- Targeted queries, archive exploration, legal leaks and disclosures (authorized sources only).

## Recommended Tools
- Shodan, Maltego, SpiderFoot, theHarvester.

## Frameworks
- OSINT Framework
- Always cross-verify sources for accuracy and chain of custody.

## Advanced Automation Techniques
- Python scripts with APIs (Shodan, X/Twitter, Censys)
- LLM-powered entity resolution and correlation
- GitHub Actions for scheduled pipelines and real-time alerts
- Recon-ng and SpiderFoot automation modules
- Playwright for dynamic web scraping
- Neo4j for relationship graphing and entity networks
- Custom OSINT bots for continuous monitoring

**Note:** All activities must remain ethical, legal, and limited to public/authorized data sources.
