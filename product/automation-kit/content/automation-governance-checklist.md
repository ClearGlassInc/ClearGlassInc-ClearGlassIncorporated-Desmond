# Automation Governance Checklist

## Ownership

- [ ] Accountable owner identified
- [ ] Reviewer identified
- [ ] Scope documented
- [ ] Approval gate documented

## Data and access

- [ ] Inputs identified
- [ ] Data classification recorded
- [ ] Data minimization considered
- [ ] Least-privilege access defined
- [ ] Secrets and credentials excluded from documentation/examples

## Reliability and safety

- [ ] Expected behavior defined
- [ ] Failure modes documented
- [ ] Human escalation defined
- [ ] Rollback/recovery documented
- [ ] Monitoring/evidence location defined

## Change control

- [ ] Test evidence available
- [ ] Material changes require renewed approval
- [ ] Audit record retained
- [ ] Review date established

## Release boundary

- [ ] No customer data included
- [ ] No proprietary third-party material included without documented rights
- [ ] No guarantee or professional-advice claim included
- [ ] No unauthorized external action enabled
