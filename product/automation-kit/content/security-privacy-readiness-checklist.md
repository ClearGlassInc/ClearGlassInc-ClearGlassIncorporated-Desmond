# Security and Privacy Readiness Checklist

This checklist is a planning aid and does not constitute a security assessment, certification, legal advice, or privacy compliance determination.

## Data

- [ ] Data types and sensitivity are documented.
- [ ] Collection is limited to what the workflow requires.
- [ ] Retention is defined.
- [ ] Sensitive or unnecessary data is excluded from examples.

## Access

- [ ] Access is least privilege.
- [ ] Secrets are stored outside source material.
- [ ] Human approvers are identified.
- [ ] Access changes are reviewable.

## Automation behavior

- [ ] Inputs are validated.
- [ ] Failure behavior is defined.
- [ ] Human escalation exists for consequential outcomes.
- [ ] Rollback/recovery is documented.
- [ ] Evidence is retained.

## Review

- [ ] Appropriate qualified security/privacy professionals are consulted where the actual deployment requires them.
- [ ] Open issues are recorded as `NOT VERIFIED` until evidence closes them.
