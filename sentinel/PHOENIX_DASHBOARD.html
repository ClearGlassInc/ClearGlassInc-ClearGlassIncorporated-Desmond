Safety invariants (enforced in code + CI)

  • No high-risk auto-exec — irreversible / risk≥70 actions are blocked until an approval is supplied.
  • Fail-closed — unverifiable confidence or unknown action ⇒ escalate, never guess.
  • Containment before remediation — spreading incidents are isolated first.
  • No failure loops — a fix that fails repeatedly for a signature is exhausted and forces escalation.
  • Tamper-evident — every step is written to the hash-chained audit log.

Where PHOENIX sits

  • Resilience persona in the PERCIVAL / SENTINEL agent family — same fail-closed doctrine.
  • Shares the hash-chained audit.AuditLog and the risk-band model of the commerce OS governance gate.
  • Pure orchestration & pure stdlib; all side effects run through injected executor / verifier adapters.
  • Ships as sentinel/sentinel/selfheal.py with tests/test_selfheal.py and a CI self-check gate.
