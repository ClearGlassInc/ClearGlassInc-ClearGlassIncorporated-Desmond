Voice-session controller mock

Exercises a local state machine only. No microphone, telephone, SIP, AI model, network call, recording, or transcript is involved.

State: IDLE
  1. Start → DISCLOSURE_REQUIRED
  2. Accept disclosure → AUTHENTICATION_REQUIRED
  3. Complete demo authentication → ACTIVE
  4. End → CLOSED; volatile state cleared

The buttons simulate control-plane transitions only. There is no caller identity verification or actual authentication in this mock.

Local acceptance checks

  • Encrypt a synthetic note; confirm a ciphertext package is shown and plaintext is not shown in the ciphertext field.
  • Decrypt with the same passphrase; confirm exact text match.
  • Change the passphrase and decrypt; confirm authentication failure.
  • Clear memory; confirm ciphertext and decrypted output disappear and decryption is disabled.
  • Run the voice mock through disclosure, demo authentication, active, and closed states.
  • Reload the page; confirm no state is restored because no browser storage is used.
