# Human Approval-Gate Model v0.1

Gate Types: No Gate (logged, reversible low risk), Review Gate (peer review), Approval Gate (manager/owner), Escalation Gate (senior), Evidence Gate (record required), Manual Intervention Gate (human must perform)

Template: Action, Risk Tier, Gate Type, Approver Role, Evidence Required, Audit Trail Location, Exception Handling

Audit Trail Fields: Who approved, when, what, source data reference, version, outcome
