# Governed AI Automation Operating Kit

## Status

**Internal MVP development and validation preparation only.** This document is a product specification, not a public listing, sales offer, legal opinion, compliance certification, or implementation engagement.

## Purpose

The Governed AI Automation Operating Kit is an original ClearGlass planning and governance toolkit for teams evaluating automation. It helps users identify practical automation opportunities, document workflows, prioritize candidates, define approval gates, assess operational risk, estimate planning value, and prepare an implementation roadmap.

Approved purpose language:

> This toolkit is designed to help teams organize, document, prioritize, and prepare automation initiatives with clearer workflows, defined ownership, approval checkpoints, and practical implementation guidance.

## Intended users

- SMBs evaluating automation
- Professional-service firms
- Agencies
- Founders and operators
- Technical teams
- Organizations considering AI-enabled workflows that need human oversight

## Approved components

1. Automation Opportunity Assessment
2. Workflow Inventory Template
3. Automation Prioritization Matrix
4. Automation Risk-Tiering Framework
5. Human Approval-Gate Model
6. Automation Governance Checklist
7. Evidence and Provenance Checklist

9. Automation ROI and Effort Calculator
10. SOP templates
11. 30/60/90-day Automation Implementation Roadmap
12. Original illustrative workflow examples

## Scope

## Calculator notice

Every ROI/effort calculator output must carry this exact notice:

> Outputs are estimates based on user-entered assumptions. They are planning aids only and do not guarantee savings, financial results, return on investment, operational performance, or business outcomes.

## Human governance model

Automation candidates should identify an accountable owner, approval point, evidence source, failure path, rollback/recovery approach, data classification, and review cadence. The toolkit documents planning controls; it does not execute customer automation.

## Release boundary

Current owner approval authorizes internal planning, creation, and validation preparation only. It does **not** authorize publication, customer outreach, marketplace listing creation, checkout activation, payment processing, advertising spend, invoice creation, contract execution, account modification, or money movement.
