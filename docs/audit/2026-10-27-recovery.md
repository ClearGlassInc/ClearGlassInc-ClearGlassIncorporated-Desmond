## Findings that need a decision

1. **D1 — licence (counsel).** The repository's terms changed from proprietary to MIT in a
   commit about something else. Code published under MIT while that file stood may carry
   MIT rights for whoever took it. Restoring the file is one command
   (`git checkout 78467ae^ -- LICENSE`). It is a legal act, not a repair, and it is not done
   here. Ask counsel whether to restore it, and what the 2026-10-23 → restore window means.
2. **D7 and the root overwrite.** Pick one. (a) Move the coin project (8 `.py` files,
   `config.ini`, its docs, `requirements.txt`, `LICENSE`, `README.md`) into its own directory
   and restore the root `README.md` and `requirements.txt` from `78467ae^`. (b) Keep it at the
   root and raise the pins to the fixed versions pip-audit names. Either way, the next
   `defender-watch` run after runners return will report these advisories.
3. **Wallet design (not fixed).** `clearglass_wallet.py:32` writes the private key to JSON
   in plaintext. `POST /wallet/create` generates keys on the server and returns them in the
   response, with CORS open to every origin. The `new_block` peer handler is a stub that
   acknowledges blocks without validating them. All are fine for a demo and must not hold
   real value.
4. **"BUY / BOOK" dock on the book pages.** `tools/shared_layers.py` adds `/logo-badge.js`,
   the site-wide brand-and-commerce dock on 185 pages, because the policy requires a brand
   mark. Its panel lists ClearGlass service offers, not the book. On a page that says "No
   purchase availability is represented here", the label can still read as "buy the book".
   The dock has no per-page opt-out, so changing this means changing a site-wide script.
5. **Workflow governance (unchanged since 10-26).** `intelligence-graph.yml` can push
   unattended without a protected environment. Six workflows grant write permissions at the
   top level. `ai-proxy-security.yml` makes one audit step non-blocking. 44 of 98 workflows
   have no `concurrency` key.
